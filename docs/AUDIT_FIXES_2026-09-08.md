# 账号隔离、浏览器环境与界面修复记录

日期：2026-09-08。范围：当前工作区源码；未发布或重新打包 Release。

## 已修复的问题

| 范围 | 原问题与修复 |
| --- | --- |
| 环境身份 | 大小写不同的 ID 在 Windows 上可能共用资料目录。现在拒绝大小写冲突、重复 ID 和 Windows 保留名称，并在批量修改前验证。 |
| 文件隔离 | junction/符号链接可能绕过资料目录检查，导致清理、偏好写入或备份访问其他环境。现在校验根目录及目标子路径，并识别便携模式下真实系统浏览器目录。 |
| Firefox 生命周期 | 启动缺少实例锁、目录验证及完整失败清理。现在增加独立运行目录、并发启动去重、启动中操作保护、就绪检查和按可执行文件及 profile 参数验证的停止逻辑。 |
| Firefox 数据清理 | 原清理名单仅覆盖 Chromium，Firefox 的 Cookie、缓存和保留选项不生效。现在使用 Firefox 文件布局，分别清理密码、localStorage、IndexedDB；同时清除 SessionStore 及恢复副本中的 Cookie，保留标签页。损坏的恢复文件会报告错误，不会假报清理成功。 |
| 代理 | 修复 HTTP 默认端口、HTTP 复用连接认证、HTTPS 协议协商，以及 Firefox 切换代理残留、SOCKS4/5 版本和坏配置静默直连。 |
| 指纹 | 修复缺失坐标被转换为 `(0,0)`、越界坐标及精度不一致。文档初始化脚本注册失败按硬失败处理，避免继续报告已保护和启动成功。 |
| 设置保存 | 串行、原子替换设置文件，写失败保留原文件；独立选项保存不覆盖其他选项。数据目录切换、浏览器启动、备份恢复互斥，失败时保持引擎与磁盘一致。 |
| 凭证与重启 | 用明确标记区分脱敏缓存与用户主动清空密码/Cookie/TOTP；启动时恢复主进程的完整配置，并在恢复完成前阻止界面提交旧缓存。 |
| 云恢复 | “保留本地”或本地配置较新时不再覆盖其浏览器数据；恢复前检查 ID、编号和运行状态；全量覆盖与局部拉取分别遵循对应范围，保留未选环境。备份采集拒绝链接目录。 |
| 导入与批量操作 | JSON 导入保留内核、账号、Cookie、指纹及高级配置；CSV 支持 BOM、多行和转义引号；批量换代理清除旧订阅/提取接口/备用代理关联。 |
| 界面 | 保存遭拒绝时不污染列表与缓存；新建语言选择生效；修复 DNT 被旧控件覆盖，以及必填字段无效时无法取消或关闭弹窗。 |

## 验证与复现入口

所有测试使用合成账号与测试目录；未读取真实账号列表、Cookie 或用户浏览器资料，也未下载依赖。

本轮结果：**34/34 个离线回归脚本通过**；真实桌面应用的新建、取消、保存及重启检查通过；指定本机 Chrome 的双环境同源存储隔离与重启持久化检查通过。JavaScript 语法和差异空白检查通过。

在 `Browserapp` 目录运行：

```powershell
npm run selftest:audit
npm run selftest:audit-ui
npm run selftest:audit-storage -- --browser "C:\Program Files\Google\Chrome\Application\chrome.exe"
```

- `selftest:audit`：离线回归，覆盖环境隔离、备份、设置、代理、指纹、协议、同步、AI、导入及主题。
- `selftest:audit-ui`：使用独立临时数据启动真实 Electron 界面，验证新建、取消、保存、关闭重启、凭证恢复与主动清空。
- `selftest:audit-storage`：两个真实 headless Chromium 实例访问同一本地站点，验证普通 Cookie、HttpOnly Cookie、localStorage、IndexedDB 相互隔离，以及关闭重启后的各自持久化；调用了项目的目录、偏好和 Cookie 导入导出逻辑。

## 验证边界

- 真实存储测试通过的是显式指定的本机 Chrome。直接启动随包 Wayfern 内核时，它要求首次条款初始化；测试明确报告 SKIP，未代用户接受条款。这不等于已经证明应用正常启动流程失败，也不构成随包内核验证通过。
- Firefox 的启动与失败清理使用受控协议/进程替身验证；本轮未完成 Firefox 全功能的真实浏览器端到端验证。
- Firefox 历史和书签共用 Places 数据库，本轮仅支持两者同时保留或同时清除；单独关闭一项会给出明确错误，避免误删仍要求保留的数据。
- 未使用真实账号登录第三方网站，未验证真实付费代理、外部 AI 服务、云存储提供商和全部原生窗口同步组合。测试通过仅代表所列覆盖范围。
- 当前目录的启动器加载 `Browserapp` 源码；重新启动应用即可加载修改。现有发布包不会因此自动更新。
