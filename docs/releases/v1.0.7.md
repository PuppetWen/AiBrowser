## 中文

- 新增“Google 默认指纹环境”按钮，与“读取本机基础参数”并排。新模式使用当前 Chromium 内核的原生 UA、硬件和图形参数，关闭指纹伪造，并保留环境数据隔离与代理配置；不会切换到系统安装的 Google Chrome。
- 修复环境 ID 冲突、并发启动、路径链接、Firefox 数据保留和部分备份恢复可能破坏环境隔离的问题。
- 修复指纹注入失败仍继续启动或导航的问题，以及代理认证、HTTPS 转发和网络配置相关错误。
- 修复配置保存后立即退出可能丢失更改、凭据恢复、JSON/CSV 导入、语言、Do Not Track 和表单取消问题。
- 修复 3D 宠物靠近桌面边缘产生无法拖动的滚动条；显示器、分辨率或 DPI 变化时同步更新宠物窗口与交互位置。
- 澄清“读取本机基础参数”、浏览器内核、原生 UA 和启动日志中的程序数量说明。
- Windows 可执行文件属性中的版本号现在与应用版本一致。

验证：38 项离线回归检查、独立数据目录的桌面保存/重启测试、真实 Chrome 原生指纹对照及存储隔离测试通过；宠物页面 15 组位置/缩放组合无滚动条。测试未使用真实平台账号；原生指纹模式不保证平台免风控。Firefox 的历史记录和书签共用数据库，目前须同时保留或同时关闭保留。

提供含内核的 Windows x86_64 ZIP、单文件便携版和安装程序。SHA256SUMS.txt 可用于校验下载文件。

## English

- Added a native fingerprint preset beside the local-parameter button. It keeps the selected Chromium runtime's native UA, hardware, and graphics values while preserving isolated profile data and proxy configuration. It does not select an installed Google Chrome browser.
- Fixed profile identity collisions, concurrent launches, linked data paths, Firefox retention, and backup restore issues affecting environment isolation.
- Stop protected startup/navigation when fingerprint injection fails; corrected proxy authentication and HTTPS forwarding behavior.
- Fixed save-and-exit persistence, credential restoration, JSON/CSV imports, language settings, Do Not Track, and form cancellation.
- Removed unresponsive desktop-edge scrollbars caused by the 3D pet overlay and updated pet geometry after monitor, resolution, and DPI changes.
- Clarified local parameter sampling, native UA display, browser kernel labels, and startup program counts.
- Windows executable version metadata now follows the application version.

Validation includes 38 offline regression scripts, isolated desktop save/restart checks, real Chrome native-fingerprint comparisons and storage isolation, and 15 pet viewport cases. No real platform accounts were used; this preset does not guarantee acceptance by platform risk controls. Firefox history and bookmark retention must currently be enabled or disabled together.
