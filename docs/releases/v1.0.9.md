## 中文

- 默认开启严格隐私保护，包括已有环境。每个环境使用独立本机网关，系统代理在启动时固定为一个端点；禁止空代理、直接连接和 PAC。
- 启动前验证代理出口及有效时区，指纹和定位权限设置完成后才放行网络。代理连接或认证失败、指纹注入或读回失败、CDP 断开时，先关闭网关及活动连接，再停止环境；运行中不会回落直连，需重新启动恢复。
- 禁用真实网页定位及 WebRTC，限制非代理 UDP、QUIC、DoH、预测和后台联网；检测页通过正在运行的网关检测出口，旧宿主 DNS 探测标记为“未执行”。严格模式拒绝宿主直连提取或刷新动态代理。
- 初始及额外启动页面在保护就绪后导航。严格模式拒绝自动恢复会话，保留已有会话文件；拒绝保护尚未完整的 Firefox 和原生指纹模式。目前支持 Windows Chromium。
- 新增“安装网络保护”入口，为独立内核添加持久 Windows 出站阻断规则。规则随应用退出保留，安装后也约束使用同一内核的兼容模式环境。

**首次启动或升级后：** 先为全部网络配置文件开启 Windows 防火墙，再进入“编辑环境 → 代理配置 → 安装网络保护”并完成管理员授权。配置固定 HTTP、HTTPS、SOCKS5 代理或可固定解析的系统代理。保护未就绪会拒绝启动；更换或移动内核后可能需要重新安装规则。兼容模式不具备相同保护。

验证：12 个相关离线及回环自测脚本通过，包括 15 组严格隐私场景、代理断线锁定、活动隧道关闭、指纹故障生命周期、检测页禁止直连、网络模式与资料隔离回归。Windows 防火墙关闭时，实际保护检查按预期拒绝。**尚未完成防火墙规则生效后的真实浏览器出站阻断及抓包验收，不能宣称零泄露。** 上游代理软件仍须关闭 DIRECT 回退；管理应用的 AI、更新、订阅导入和扩展下载不属于每个浏览器环境的网络通道。指纹读回检查只覆盖已列明字段，不能保证所有浏览器接口或网站均一致。

成品验证采用静态内容、版本及校验和一致性检查。旧版本曾做启动、安装及卸载测试；本次尚未重跑真实安装与卸载，以免覆盖本机已有安装。

提供含内核的 Windows x86_64 ZIP、单文件便携版和安装程序，以及 `SHA256SUMS.txt`。详细保护条件见[隐私修复说明](https://github.com/PuppetWen/AiBrowser/blob/v1.0.9/docs/PRIVACY_HARDENING_2026-10-02.md)。

## English

- Enabled strict privacy by default for new and existing environments. Each environment uses its own local gateway; system proxies are pinned to a fixed endpoint at startup. Empty proxies, direct connections, and PAC are rejected.
- Validate the proxy exit and timezone before startup, then open the gateway after fingerprint and geolocation-permission setup. Proxy connection or authentication failures, fingerprint setup or readback failures, and CDP disconnections close the gateway and active connections before stopping the environment. Runtime failures require a restart and do not fall back to a direct connection.
- Disable real webpage geolocation and WebRTC, and restrict non-proxied UDP, QUIC, DoH, prediction, and background networking. The start page checks the exit through the running gateway; the legacy host DNS probe is marked as not performed. Strict mode rejects direct host requests for dynamic proxy extraction or refresh.
- Navigate initial and additional startup pages after protection is ready. Strict mode rejects automatic session restoration while retaining existing session files. It also rejects Firefox and native fingerprint mode; strict protection currently supports Windows Chromium.
- Added an Install network protection action for persistent Windows browser outbound rules. Rules remain after the app exits and also affect compatibility-mode environments using the same kernel.

**After installing or upgrading:** Enable Windows Firewall for all network profiles, then open Edit environment → Proxy configuration → Install network protection and approve the administrator prompt. Configure a fixed HTTP, HTTPS, or SOCKS5 proxy, or an enabled system proxy that can be pinned to a fixed endpoint. Startup is blocked until protection is ready. Replacing or moving the kernel may require installing the rules again. Compatibility mode does not provide the same protection.

Validation: 12 relevant offline and loopback regression scripts passed, including 15 strict-privacy groups covering gateway failure latching, active-tunnel closure, fingerprint failure lifecycle, prevention of direct start-page probes, network modes, and profile isolation. The actual Windows protection check rejected startup with the firewall disabled. **Real-browser outbound enforcement and packet-capture acceptance testing with active firewall rules are still pending; zero leakage has not been established.** Upstream proxy software must also disable DIRECT fallback. AI, updates, subscription imports, and extension downloads from the management app are outside each browser environment's network channel. Fingerprint readback covers the documented fields and does not prove consistency across every browser API or website.

Package verification uses static content, version, and checksum consistency checks. Earlier versions underwent startup, installation, and uninstall tests; these have not been repeated for this version, to preserve the existing local installation.

Includes Windows x86_64 ZIP, single-file portable executable, installer, and `SHA256SUMS.txt`. See the [privacy repair details](https://github.com/PuppetWen/AiBrowser/blob/v1.0.9/docs/PRIVACY_HARDENING_2026-10-02.md) for protection requirements.
