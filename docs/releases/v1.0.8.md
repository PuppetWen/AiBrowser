## 中文

- 全部 6 套主题、7 种深浅外观统一液态玻璃材质，保留各主题的字体、布局与配色特点。
- 工具栏、文件与内核路径框、输入框、下拉菜单、弹窗和同步浮条增加通透染色、背景模糊与玻璃边缘高光。
- Windows 11 22H2 及以上的主窗口和同步浮条使用系统原生亚克力背景，保留窗口缩放与最大化；macOS 接入系统 vibrancy，不支持的系统使用清晰底色回退。
- 修复旧主题实心表格条纹、暗色分页文字、提示框、日志背景和 AI 选中按钮的可读性问题，保留状态区分与键盘焦点。
- 适配减少透明度、高对比度和减少动态效果；弹窗玻璃使用独立背景层，避免干扰下拉菜单定位与鼠标操作。

验证：Windows 隔离 Electron 渲染覆盖 7 种主界面外观与 7 种浮窗外观；260 组文字与实际背景的对比度采样全部达到 4.5:1，最低 4.79:1。通过弹窗、主题菜单、输入、浮条展开/折叠、1024×768 布局和减少动效/透明度检查。主窗与浮窗的 Windows 原生亚克力已通过 DWM 实测；macOS 路径与旧系统回退通过模拟检查，未进行 macOS 实机验证。

提供含内核的 Windows x86_64 ZIP、单文件便携版和安装程序。SHA256SUMS.txt 可用于校验下载文件。

## English

- Added a shared liquid-glass material across all six themes and seven appearance variants while retaining each theme's typography, layout, and color family.
- Added translucent tints, backdrop blur, and reflective edges to toolbars, file and kernel paths, inputs, menus, dialogs, and the floating sync controller.
- Enabled native acrylic for the main window and sync controller on Windows 11 22H2 or later, preserving resizing and maximization. macOS uses system vibrancy; unsupported systems retain readable fallback backgrounds.
- Fixed opaque table stripes, low-contrast pagination, hints, log surfaces, and selected AI controls. Preserved status distinctions and keyboard focus.
- Added reduced-transparency, high-contrast, and reduced-motion handling. Dialog blur uses a separate background layer to preserve dropdown positioning and pointer input.

Validation: isolated Windows Electron rendering covered seven main-window and seven floating-controller variants. All 260 sampled text/background pairs met 4.5:1 contrast, with a minimum of 4.79:1. Dialogs, menus, input, controller expansion/collapse, 1024×768 layouts, and reduced-motion/transparency checks passed. Windows acrylic was verified through DWM; macOS and older-system fallbacks were tested with mocks, not on a physical Mac.

Includes Windows x86_64 ZIP, single-file portable executable, and installer with bundled browser kernels. Use SHA256SUMS.txt to verify downloads.
